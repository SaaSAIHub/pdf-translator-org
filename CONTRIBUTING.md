# Contributing to PDFTranslator.org Documentation

This repository contains the official product overview, usage guides, and published translation examples for [PDFTranslator.org](https://pdftranslator.org/). It does not contain the website application or translation engine.

## Product feedback

Report bugs and suggest features through the [PDFTranslator.org FeedLog portal](https://pdftranslator-org.feedlog.ai/). GitHub Issues are disabled so product feedback stays in one place.

Describe the document type, language pair, selected translation style, browser, and the visible problem. Share only non-sensitive examples. Do not publish private documents, task identifiers, or signed upload/download URLs.

## Documentation corrections

Pull requests are welcome for factual corrections, clearer instructions, broken links, and translation improvements. Keep changes focused and explain the correction in English. Use English commit messages, for example `docs: clarify monthly PDF translation allowance`.

The default README is English. Simplified Chinese, Spanish, and Brazilian Portuguese versions live alongside it and link to each other. When changing a product fact, update all four versions. Detailed guides remain in English.

Verify claims against the live website, current policies, and observed behavior. If sources conflict, explain the discrepancy in the pull request rather than inventing a resolution. Do not add unsupported accuracy, speed, ranking, privacy, or formatting guarantees.

Keep brand spelling as **PDFTranslator.org** or **PDFTranslator**, and link to **https://pdftranslator.org/** or its supported language homepages. Use descriptive headings and natural wording instead of keyword lists or repeated promotional links.

## Images and examples

Use images you are authorized to share. Check for personal information, confidential content, browser account details, and outdated limits before submitting them. Store approved images in `assets` with descriptive names and useful alt text. Do not include temporary signed asset links or generated pictures presented as product results.

The current comparison images show English originals and Chinese translations from the product's published examples. Do not describe them as a new test, a user endorsement, or proof of identical results on all files.
